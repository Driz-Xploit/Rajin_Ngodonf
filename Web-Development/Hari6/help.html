1. YTStream ini sudah otomatis loop embed

2. Jika ingin menggunakan fitur YT Embed, masukkan ID embed saja (tanpa URL!).
Contoh: GakoOKlvKb4

3. Jika ingin memasukkan ID embed video dan playlist, gunakan '&' sebagai penengah (VIDEO_ID&PLAYLIST_ID).
Contoh: GakoOKlvKb4&RDGakoOKlvKb4

4. Tambahkan video sendiri ke dalam folder test/ jika ingin menggunakan fitur Local Video. (Masukkan filename saja tanpa path).
Contoh: test.mp4
